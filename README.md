VoxGuard AI is a real-time cybersecurity platform designed to detect and prevent AI-generated voice cloning, deepfake audio, and synthetic impersonation attacks (such as those generated by **Gemini Live**, **ElevenLabs**, VALL-E, and voice conversion vocoders) during live calls and voice interactions.

---

## 🚀 Key Features

* **Multi-Layer Anti-Spoofing Architecture**:
  * **Deep Neural Classifier**: Fine-tuned Wav2Vec2 (`facebook/wav2vec2-base` + classification head) evaluating contextual audio representations.
  * **Acoustic Vocoder Phase Analysis**: Detects high-frequency phase leakage ($>3800\text{ Hz}$ shelf), spectral rolloff, spectral centroid shifts, and Wiener flatness anomalies characteristic of neural vocoders (HiFi-GAN, SoundStream, EnCodec).
  * **Loudspeaker Replay Signature Detection**: Identifies mobile micro-transducer resonance ($2.2\text{ kHz} - 4.5\text{ kHz}$) and low-frequency cut-off ($<180\text{ Hz}$) when an attacker plays synthetic audio through a phone.
* **Intelligent Voice Activity Detection (VAD)**:
  * Energy and vocal-band spectral ratio filtering prevents ambient room noise, fan hiss, or microphone silence from triggering false alarms.
  * Clean three-state verdict: **Idle** (silence/ambient), **Bonafide** (natural human voice), and **Spoof** (AI clone/synthetic audio).
* **Streaming WebSocket Engine (`/ws/monitor`)**:
  * Processes continuous $16\text{ kHz}$ PCM audio frames with exponential moving average (EMA) smoothing for stable live classifications without flicker.
* **Interactive Cybersecurity SOC Dashboard**:
  * Clean, high-contrast light theme engineered for security operations centers.
  * Real-time risk gauge, live waveform visualizer, threat event logs, and dynamic challenge-response verification phrases.

## 🛠️ Tech Stack

* **Backend**: Python 3.11, FastAPI, PyTorch, HuggingFace Transformers, Librosa, WebSockets, Uvicorn, Docker.
* **Frontend**: React 19, Vite, Vanilla CSS + Tailwind utility tokens, Lucide Icons, Recharts.
* **Deployment Targets**: Render (Docker web service for backend), Vercel (static edge deployment for frontend).

## ⚡ Quick Start (Local Development)

### 1. Backend Setup

```bash
cd backend

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Place your trained weights in backend/app/models/model_weights.pth
# Then start the API server:
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Verify backend health:
```bash
curl http://localhost:8000/health
# {"status":"ok","model_ready":true}
```

### 2. Frontend Setup

```bash
cd frontend

# Install npm dependencies
npm install

# Start development server
npm run dev
```

Open `http://localhost:5173` in your browser.

## 🌐 Production Deployment

### Backend on Render
1. Create a **New Web Service** connected to this repository.
2. Select **Root Directory**: `backend`.
3. Select **Runtime**: `Docker`.
4. Instance Type: **Standard (2GB RAM minimum)** for PyTorch inference.
5. Set environment variable: `FRONTEND_ORIGIN = https://<your-vercel-domain>.vercel.app`.

### Frontend on Vercel
1. Import repository to Vercel.
2. Set **Root Directory**: `frontend`.
3. Set Environment Variable: `VITE_BACKEND_WS_URL = wss://<your-render-domain>.onrender.com/ws/monitor`.
4. Deploy!

For complete deployment instructions, see [DEPLOYMENT.md](DEPLOYMENT.md).
