# Model Weights Directory

Place your fine-tuned `model_weights.pth` file here.

- Expected file: `model_weights.pth` (~360MB)
- Architecture: `RealWav2Vec2Classifier` (`facebook/wav2vec2-base` + classification head)
- Note: Large binary files (`*.pth`, `*.onnx`) are excluded from Git to comply with GitHub's 100MB file limit.
